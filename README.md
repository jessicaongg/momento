# momento stock book

Stock, sales, expenses, restock list and supplier links for momento.co (Jessica & Valerie).

- Hosted on GitHub Pages; data, logins and photos live in Supabase.
- `config.js` holds the Supabase project URL and publishable key (safe to be public: the database only lets emails on the `members` list read or change anything).
- Install on a phone: open the site in Safari (iPhone) → Share → Add to Home Screen, or Chrome (Android) → ⋮ → Add to Home screen.
